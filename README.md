# HERO GRAM Client

Separate Expo + React Native + TypeScript Android-first messenger prototype.

## Run
1. Install Node.js LTS.
2. Run `npm install`.
3. Run `npx expo start`.
4. Open Expo Go on Android and scan the QR code.

Login and messages are demo/local only. There is no real authentication, Telegram verification, server delivery, or persistence yet. The existing bot/server are not changed.

Future API URL: set `EXPO_PUBLIC_API_BASE_URL` after the FastAPI server is ready.
